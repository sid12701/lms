## Risks and Blockers

1. **Postman MCP authentication timed out** — cloud workspace tools (`getWorkspaces`, `runCollection`, `createCollection`) unavailable until OAuth completes.
2. **Docker daemon not running** — Postgres/Redis/RabbitMQ/MinIO unavailable; backend will fail without remote DB in `.env`.
3. **Document storage** — default R2 provider without credentials blocks UC-019.
4. **OPS vs ADMIN payment authorization mismatch** — UI may show actions that API rejects (403).
5. **Password rotation state** — bootstrap `ops.admin` password may already be rotated in DB; Postman env must use `admin_new_password`.
6. **Destructive data** — full E2E creates LSPs, loans, payments; use isolated DB or cleanup plan.
